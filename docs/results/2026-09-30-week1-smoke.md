# Week 1 smoke run: first real pipeline runs

- **Date:** 2026-09-30
- **What ran:** the multi-agent pipeline (planner, coder, reviewer) on the five Week 1 `dev` tasks for demo repo `taskcli`, one run each.
- **Models:** `gemini-3.8-flash` for all three roles, temperature 0, structured output through ADK's `set_model_response` tool.
- **Sandbox:** local Docker. Scoring ran in a second sandbox against the hidden tests.
- **Raw data:** `results/20260930T111728Z.json`, `results/20260930T112058Z.json`.

This is a smoke test of the machinery, not a benchmark result. Five tasks, one repeat, no baseline and no held-out split. Prompts were not tuned against these tasks.

## Observations for Week 2

1. **The coder used exactly 25 tool calls in two of four runs, which is the per-turn cap.** Either it is a coincidence or something is steering the model to stop there. Check the events for those two runs before tuning. If it is a coincidence, harder tasks will hit the cap and fail as budget.
2. **Input tokens dominate cost.** tc-004 sent 356k input tokens for 18k output. The coder re-sends its growing history on every tool call; a tighter plan (fewer files to read) or trimming old tool output would cut cost.
3. **The tasks are too easy to tell systems apart.** Everything resolved first time. The Week 2 task set needs harder and "tempting" tasks, or the single-agent baseline will tie.
4. **The loops need a real-model test.** No run exercised a test-fix return or a review return.
5. **Runs are invisible outside the terminal.** Nothing is exported to Cloud Trace from local runs yet.
