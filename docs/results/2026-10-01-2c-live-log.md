## Decisions (owner, 2026-10-01)

- **1A, a demo organisation.** The demo repositories live in a separate GitHub organisation, `issue-to-pr-demo`, not in the owner's personal account.
- **2A, a fine-grained token in a file.** Resource owner `issue-to-pr-demo`; only the three demo repositories; Contents, Issues and Pull requests read and write, Metadata read, nothing else; 30-day expiry. Stored in `~/.config/issue-to-pr/github-token` (mode 600) and read only by `app/github_client.py`.
- **6A, all 15 dev tasks.** Every dev task gets a `demo/<task-id>` branch. Held-out tasks are never published.
- **Commit identity.** Demo commits use the owner's GitHub noreply address, not a personal email.
- **Approvals given in session:** creating the demo repositories (Task 7), live demo runs on real issues (Task 8), paid evals and probe runs (Task 12). Caps: stop if the live runs pass $5, or Week 2C as a whole passes $30.
